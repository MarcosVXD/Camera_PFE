
# Captura de Fotos

## Integrante
- Marcos

## Descrição
Aplicação web que permite capturar fotos com a câmera, aplicar filtros e adicionar uma identificação com a data e a hora.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- MediaDevices e getUserMedia
- Canvas

## Funcionalidades
- Ligar e desligar a câmera.
- Capturar fotos.
- Aplicar filtros de cor original, preto e branco e negativo.
- Adicionar identificação, data e hora.
- Visualizar e baixar a imagem.
- exibir fotos em minatura como galeria
